# SmartRoute-ADMM

## Overview

SmartRoute-ADMM is an AI-powered Automated Bus Scheduling and Route Management System designed for general bus transportation networks. The system leverages real-time passenger data, traffic analytics, and resource optimization techniques to enhance operational efficiency, reduce wait times, and improve last-mile connectivity.

## Features

- **AI-Based Scheduling**: Dynamically adjusts bus schedules based on real-time passenger data to optimize fleet usage.
- **Resource Optimization with ADMM**: Uses the Alternating Direction Method of Multipliers (ADMM) to allocate resources efficiently and minimize operational costs.
- **Hierarchical ADMM for Peak Hours**: Balances schedules considering peak-hour demands, driver preferences, and bus capacity.
- **GIS-Based Route Management**: Real-time route mapping and adjustments to optimize travel paths and reduce congestion.
- **EV/Hybrid Feeder Carts**: Sustainable last-mile connectivity using electric/hybrid vehicles.

## Innovation & Uniqueness

- **ADMM and Hierarchical ADMM Implementation**: Advanced optimization techniques for resource allocation and scheduling.
- **Real-Time Footfall Prediction & Dynamic Scheduling**: Enhancing responsiveness to passenger demand.
- **Feeder Cart Integration**: Extending public transport reach using EV/hybrid micro-transit solutions.
- **GIS-Based Real-Time Route Management**: Ensuring optimal and adaptive route planning.

## How It Solves the Problem

- Automates scheduling to minimize human error and increase efficiency.
- Uses GIS-based optimization to improve route management and reduce congestion.
- ADMM optimizes resource allocation, reducing overall operational expenses.
- EV/Hybrid feeder carts enhance last-mile connectivity, especially in underserved areas.

## Technical Approach

### Technologies Used:

- **AI & Machine Learning**: Predictive analytics for footfall estimation and demand-based scheduling.
- **ADMM Optimization**: Distributed optimization technique for real-time resource management.
- **GIS & Mapping Tools**: Real-time route mapping and adjustments using geospatial technologies.
- **Elastic Stack (ELK)**: Used for real-time monitoring and observability.
